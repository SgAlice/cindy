# Fork 的 Claude Code 注入与额度精简

本 fork 的所有者于 2026-11-07 明确批准下列提示词改动。此改动不是全量移除宿主规则，也不替换 Claude Code 原生系统预设。

## 改动范围

- 所有调用既有说明构造器的路径不再注入界面语言、文言风格、查看设备名称/ID、手机输出偏好。内部设备盖章、授权与远控保留。
- 交接摘要不再从 sourceDevice 生成设备名称/ID；其他发送者、共享成员、插件等来源归属保留。旧原生上下文中已经存在的文字不会被本次修改追溯删除。
- 共享宿主提示词去掉 Cindy 身份与源码来源介绍。新默认伙伴模板不再指定 Cindy 身份；旧模板识别保留，不重写已有伙伴资料。
- Claude Code 本地与 SSH 分支都不再追加 Cindy Memory 规则/索引、Cindy 用户自定义提示词、伙伴身份/能力上下文/用户资料。Claude Code 不再装入 cindy_memory MCP 或创建 Cindy Memory flush 控制器；原生自动压缩保留。
- 普通 Claude Code 创建入口不再读取并追加 .cindy/project-knowledge/ 入口。文件与既有记忆数据不删除。
- Claude 订阅额度的 CLI get_usage 请求实现、刷新 reader、配额缓存读写和 SDK 配额落库监听移除；多账号池不再查询或缓存 Claude 余量。
- 设置页、账号列表、模型选择器、任务额度条和额度总览不再显示 Claude 配额。兼容 IPC 入口返回 null，刷新调用无副作用；其他供应商的额度功能保留。

## 明确保留

Claude Code 的 preset: 'claude_code'、可执行文件选择、登录和正常模型调用、原生配置来源与记忆设置、工具权限判定均未调整。不读写用户真实 ~/.claude 或凭据。

cindy-ui、计划写法、提交 attribution、业务归属、Skill 优先级、插件发现等未获批准移除的规则继续保留。伙伴的既有权限与配置隔离也不改变：去掉人设不等于把伙伴变为完全等同终端的 CLI。Cindy Memory/自定义上下文的引擎级停用仅针对 Claude Code，不改变 Codex/Pi 的对应功能。

## 验证与限制

最初的隔离验证使用临时目录里的 Vitest 3.2.4 和 TypeScript 5.7.3。后续为打包按锁文件安装构建依赖，并使用仓库实际依赖执行进一步检查；安装脚本下载运行资源，但不执行 Claude Code。所有步骤不启动已安装 Cindy，也不运行真实 CC 或真实 Claude 请求。

隔离 runner 对测试模块禁用真实 child_process 与 fetch；账号控制测试以进程内 EventEmitter 模拟 CLI，测试凭据仅为临时目录的人工 fixture。

已执行的 12 个测试文件共 162 项通过，覆盖：

- Claude 追加段实际构造：被移除的私有上下文不进入输出，其余宿主规则与执行环境仍在。
- 界面语言、设备说明和 legacy 手机路径不注入；内部来源盖章保留。
- 交接摘要保留授权来源但不带设备信息。
- 默认伙伴新旧模板兼容，不把用户修改过的资料认作默认模板。
- 本地与远程 Claude 配额入口、强制刷新、账号池查询和旧持久快照均不恢复配额读写。
- 配额 UI 共享判据不提供 Claude reader，其他供应商不受影响。

新增/调整测试的依据是本次所有者批准的行为变更；原测试验证的是旧的注入、配额采集行为，不能覆盖停用后的隐私与无副作用要求。新增纯逻辑 providerQuotaSource.test.ts 与既有 jsdom 组件测试环境不同，直接验证共享生产判据，无需启动 UI。其最小输入是一个已连接的内置 Claude 或自定义 Claude 订阅连接；tier 为 unit。隔离运行整组耗时约 1 秒，无真实网络与 CLI。
